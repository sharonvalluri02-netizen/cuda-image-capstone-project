# GPU-Accelerated Image Processing Using CUDA

## Project Overview

This project implements GPU-accelerated image processing using custom CUDA kernels.

A dataset containing 120 small RGB images is generated automatically. Each image is processed on the GPU using two CUDA kernels:

1. RGB-to-grayscale conversion
2. Sobel edge detection

Each CUDA thread processes one image pixel, allowing thousands of pixels to be processed in parallel by the GPU.

## Why This Meets the Assignment Requirements

### Dataset

The project generates:

- 120 images
- 256 x 256 pixels each
- RGB PPM format

The dataset is generated by `generate_dataset.py`, so no external image download is required.

### GPU Computation

The CUDA source contains two `__global__` kernels:

```cpp
__global__ void rgbToGrayKernel(...)
```

and

```cpp
__global__ void sobelKernel(...)
```

They are launched using CUDA's kernel-launch syntax:

```cpp
rgbToGrayKernel<<<grid, block>>>(...);
sobelKernel<<<grid, block>>>(...);
```

The program transfers image data from host memory to GPU memory with `cudaMemcpy`, performs the processing on the GPU, and copies the result back to the CPU.

## Technical Description

### RGB to Grayscale

For each pixel, the GPU calculates:

```text
gray = 0.299R + 0.587G + 0.114B
```

Each pixel is assigned to a CUDA thread.

### Sobel Edge Detection

The second CUDA kernel applies horizontal and vertical Sobel operators to neighboring grayscale pixels.

The approximate gradient magnitude is calculated as:

```text
magnitude = |Gx| + |Gy|
```

The resulting edge image is written to the output directory.

## Parallelization

The program uses:

```cpp
dim3 block(16, 16);
```

and calculates a two-dimensional grid based on image dimensions.

For a 256 x 256 image this creates enough CUDA threads for every pixel.

## Output Format

The processed images are saved as grayscale PGM files:

```text
image_001_edges.pgm
image_002_edges.pgm
...
image_120_edges.pgm
```

PGM was selected because it is a simple binary image format and does not require external image-processing libraries.
